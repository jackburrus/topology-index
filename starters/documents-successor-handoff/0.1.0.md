# Documents successor handoff

Topology Index starter formation. Provenance `synthetic`, status `unvalidated`.
It has never been run or measured by this service, carries no evidence, and is not signed.
Copy it, change what your workload needs, and register it as your own private candidate;
registering it creates no evidence either.

A starting point for the `outlasts_one_context` row of the decision guide at
[/patterns/index.md](/patterns/index.md), which starts with
[successor_handoff](/patterns/successor_handoff.md): a document review whose source
material and open questions outlast one context window or session. If rediscovery is cheaper
than writing the dossier, use a single agent instead.

This deployment cannot execute it:

- its task class is not one this deployment evaluates.
- it declares a `custom` topology with a predecessor and successor handoff.
- its successor-handoff pattern is not among this deployment’s executable patterns.

A runner here refuses it rather than reducing it to a simpler arrangement. Run it on an
executor that supports each of these, and compare it against a strong single agent on the
same work.

## Predecessor

Read the assigned material and keep a dossier with confirmed facts, source locations, open
questions, discarded interpretations and the next concrete steps. Mark what you did not read
and do not turn an assumption into a fact merely to make the handoff shorter.

## Successor

Read the dossier before the source material. Check its highest-risk claims against the source,
continue from the listed next steps, and record corrections separately from inherited facts.
Finish with the answer, its supporting locations and the gaps that remain.
